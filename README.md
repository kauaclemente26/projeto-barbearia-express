#  Protótipo de App de Agendamento - Barbearia Express

Este projeto fictício foi desenvolvido para a disciplina de Design Profissional do curso de Gestão de TI (2º semestre). O foco foi criar a interface de um sistema de agendamentos focado na experiência do usuário.

---

##  Objetivo do Projeto
O objetivo foi resolver o problema de marcação de horários de uma barbearia, substituindo as mensagens manuais por um aplicativo intuitivo. 

A solução buscou:
*   Reduzir o tempo que o cliente gasta para escolher um serviço e um barbeiro.
*   Criar um fluxo visual limpo, moderno e de fácil navegação para qualquer smartphone.

---

##  Tecnologias Utilizadas
*   **Figma:** Para a criação do wireframe e do protótipo interativo das telas.
*   **Kanban (Trello):** Para organizar as etapas de pesquisa, desenho e refinamento do app.
*   **Markdown:** Para a estruturação desta documentação.

---

##  O que Aprendi
*   **UX/UI Design:** Como aplicar cores, contrastes e botões claros para guiar o usuário sem confusão.
*   **Visão de Negócio:** Como alinhar as regras da empresa (horários disponíveis, serviços) com uma interface simples.
*   **Prototipagem:** Como criar interações entre telas para simular o funcionamento real do aplicativo antes do desenvolvimento.
